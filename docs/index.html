产品介绍

网页取色，不该这么麻烦

设计师、前端工程师、运营同学都需要的页面配色信息，现在一次点击就能完整拿到。

颜色藏在各处

文字、背景、边框、半透明遮罩…… 一个页面的配色往往散落在几十上百个 DOM 元素里， 想完整收集并不容易。

手动取色太慢

逐个打开开发者工具、复制色值、再粘贴进设计稿，做一份完整的页面色板常常要花上半小时。

交给拾色助手

一次点击扫描整页颜色，自动过滤透明色、去重并统计出现次数，勾选后按需要的格式一键导出。

核心功能

六个功能，覆盖完整取色流程

从扫描页面到导出文件，每一步都尽量少点击、少等待。

一键扫描

自动解析页面内所有元素的文字色、背景色与可见边框色，无需逐个检查。

手动取色

内置浏览器 EyeDropper 吸管，点击页面任意位置取色，支持兼容性检测与提示。

智能去重

自动过滤 rgba(0,0,0,0) 等透明无效色值，相同色值合并统计出现频次。

色板预览

新标签页网格展示全部颜色，点击色块即可复制 HEX 色值，半透明色也能看清。

自由勾选

支持全选、反选与清空，按出现频次或色相排序，只导出真正需要的那几个颜色。

多格式导出

支持 CSS 变量、SCSS 变量、JSON 与 TXT，文件名按 page_color_001 自动编号。

安装步骤

四步装进 Edge，永久可用

插件以「加载已解压的扩展程序」方式离线安装，不需要上架商店。

  1. 1

    下载插件压缩包并解压

    点击页面底部的「下载插件」获取 ColorPick-1.0.0.zip，解压到任意文件夹， 例如 D:\ColorPick。

  2. 2

    打开 Edge 扩展管理页

    在地址栏输入 edge://extensions/ 并回车。

  3. 3

    开启「开发人员模式」

    打开扩展管理页侧边栏中的「开发人员模式」开关，页面会出现加载扩展相关按钮。

  4. 4

    加载已解压的扩展程序

    点击「加载解压缩的扩展」，选择第 1 步解压出的文件夹。安装完成后，可在工具栏的扩展菜单中固定 ColorPick 图标。

提示：首次安装后打开任意网页，右下角会出现「拾取颜色」悬浮按钮；若没有显示，可刷新页面或点击工具栏图标。
